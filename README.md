## Project Overview

A dynamic promotional countdown web application
built with HTML, CSS and vanilla JavaScript.

The application is designed to automate the visual
presentation of recurring monthly promotions,
providing a real-time countdown and automatic
promotion status updates.

This project is inspired by a real e-commerce
solution implemented for Libre Arte Accesorios.

## Business Problem

Recurring promotional campaigns require continuous
updates to banners, promotional messages and dates.

This application aims to automate these updates,
reduce manual work and improve the user experience.

## Planned Features

- Real-time countdown timer.
- Automatic monthly promotion scheduling.
- Promotion activation on the 15th of every month.
- Automatic countdown reset after the promotion.
- Colombia timezone support (America/Bogota).
- Responsive interface for desktop and mobile.
- Dynamic promotional messages.
- Automated JavaScript testing.
- Public deployment using GitHub Pages.

## Business Logic

| Period | Application Status |
|---|---|
| Days 1 - 14 | Countdown to promotion |
| Day 15 | Promotion active |
| Days 16 - 31 | Countdown to next month |
